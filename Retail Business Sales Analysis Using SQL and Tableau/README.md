# 📊 Retail Business Sales Analysis Using SQL and Tableau

## 🧾 Project Overview

This project analyzes **retail business sales data** to uncover trends, customer purchasing behavior, and product performance insights using **SQL for data analysis** and **Tableau for interactive dashboard visualization**.

The project demonstrates the ability to transform raw transactional data into **actionable business insights** that support data-driven decision-making.

---

## 🎯 Business Objective

Retail companies generate high volumes of sales and customer data. The objective of this project is to analyze this data to answer key business questions such as:

* Which products generate the highest revenue?
* Who are the most valuable customers?
* What are the monthly and seasonal sales trends?
* Which regions contribute most to sales performance?
* How can businesses improve profitability and customer retention?
